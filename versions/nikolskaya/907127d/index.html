02 / RAG · 180 ПРЕЗЕНТАЦИЙ

Поиск по корпоративным материалам

MVP помогает находить информацию в базе из 180 презентаций. RAG сначала выбирает подходящие фрагменты документов, затем формирует ответ на их основе.

Как проверить качество

Для такого поиска важны вопросы с известным ответом, проверка найденных фрагментов и возможность открыть источник. В публичном описании оставлены принцип работы и объём базы без внутренних материалов.

03 / EASYOCR · 74 ТЕСТА

От изображения к проверенному тексту

Прототип обработки сканов с EasyOCR. Набор из 74 тестов помогает проверять, как пайплайн ведёт себя на разных документах.

Что важно в таком процессе

Распознать символы недостаточно: результат нужно сопоставить с ожидаемыми полями, заметить пропуски и передать сомнительные случаи на проверку. Пример на сайте обезличен.
