## Что сохранено

Новая визитка: имя слева, прозрачный аватар справа, шесть логотипов в строку, выровненный левый край шапки. Реакция головы на курсор усилена. Это наклон плоского PNG, а не готовая 3D-модель.

«Опора»: вымышленная школа психологии, восемь разделов, фотографии пользователя, ссылки на образовательные источники, анимация текста и фотографий при прокрутке. Верхний логотип удалён. Это учебный пример, не реальная лицензированная школа.

Обновление 14 ноября: одна веб-страница с инструкциями и копированием цельных промптов; обязательная установка скиллов до создания сайта; референсы Awwwards вместо перехода в репозиторий Екатерины; аккаунт GitHub не нужен для первого урока. PDF обновлён (12 страниц).

Гайд: чёрный фон до краёв страницы, два примера сайтов, универсальные промпты с полями для своих данных, ссылки на навыки и установка, работа с референсами и Pinterest, конкретные правки по скриншотам, примеры до/после, создание аватара. Публикация через GitHub и деплой оставлены темой второго урока.

Карусель: девять JPG 1080 × 1350. Последовательность: обложка → задача → стиль → правки → цвета → фото → аватар → проверка → призыв написать «сайт». Готовые изображения и программа сборки сохранены отдельно. Публикация в Instagram не выполнялась.

## Идентика

Текущий гайд и карусель: фон около чёрного, молочно-белый текст, холодный голубой акцент. Карусель использует #0b0c0e / #f6f5f0 / #91afff; безопасные поля 65 px, одинаковые верхние подписи и нумерация. Шрифт карусели — Arial/Arial Bold. Визитка использует выразительную узкую типографику Oswald и контраст чёрного с белым. «Опора» намеренно имеет другую редакционную стилистику: кремовый фон и крупная антиква.

В `materials/identity/reference/tokens.json` сохранены ранее существовавшие бренд-токены. Они не означают, что все предыдущие артефакты уже переведены на единую систему. Отдельно сохранены правила ScreencastFrame и шаблона nikolskaya-reels. Для вертикального видео — 1080 × 1920; это отдельный формат от карусели 1080 × 1350.

## Запуск и пересборка

Сайты статические. В корне репозитория:

```sh
python3 -m http.server 8080
```

Открыть `http://localhost:8080/nikolskaya-romans/` или `/opora/`.

Для материалов:

```sh
python3 -m pip install -r materials/source/requirements.txt
python3 materials/source/build-guide-v2.py
python3 materials/carousel/build.py
```

Сборщик PDF рассчитан на Google Chrome в стандартной папке macOS. На другой ОС замените `executable_path` в файле на путь установленного Chrome либо используйте установленный Playwright Chromium. Сборщик карусели использует системный Arial macOS: на другой ОС укажите свой путь к Arial или совместимому кириллическому шрифту. PDF пересобирается в `materials/guide/`, слайды — в `materials/carousel/`. Перед запуском сохраните текущий коммит: сборка перезаписывает выходные файлы.

## Публикация

GitHub Pages настроен на ветку `main`, корень репозитория. После push дождитесь успешной сборки Pages. Обновляйте именно папки `nikolskaya-romans/` и `opora/`: локальные рабочие проекты из чата могут существовать отдельно и автоматически не синхронизируются.

В данном снимке сохранены готовые статические исходники сайтов: HTML, CSS, JS, шрифты и используемые изображения. Исходные большие видео, приватные аккаунты, токены и оригиналы личных фотографий отдельно не выгружались.

## Резервные версии и восстановление

- `backup-before-materials-2026-11-11` — состояние до добавления гайда и карусели.
- `session-2026-11-11-materials-v1` — полный снимок после добавления материалов.
- История `git log --date=iso --oneline` показывает реальные даты и коммиты; старые несуществующие коммиты не восстановлены искусственно.
- `materials/SHA256SUMS.txt` содержит контрольные суммы упакованных материалов.
- На странице GitHub можно скачать ZIP выбранного тега. Это резервный снимок в том же сервисе, а не независимый внешний бэкап.

Чтобы безопасно посмотреть старую версию:

```sh
git switch -c review-old-version backup-before-materials-2026-11-11
```

Для возврата опубликованной версии используйте отдельный новый коммит восстановления; не переписывайте историю main без необходимости.

## Выдача по слову «сайт»

`materials/delivery.json` — заготовка, не активная автоматизация. После появления рилса: привязать его к ChatPlace → отправлять ссылку на гайд в директ → проверять успешную отправку → отвечать именно в ветке исходного комментария «Отправила гайд в директ 💙». При ошибке DM не публиковать подтверждение; при обращении только в директ не создавать публичный комментарий. Длинные Instagram ID хранить строками.

Google Диск ещё не подключён и PDF туда не загружен. До подключения публичный PDF доступен через страницу материалов GitHub Pages. ChatPlace не активирован; рассылки и сообщения людям не отправлялись.
