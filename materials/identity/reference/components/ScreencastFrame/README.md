# ScreencastFrame

Рамка вертикального скринкаста 9:16 (1080 × 1920) для Reels, сторис и Telegram: заголовок, окно с записью экрана, субтитры, шаги, футер.

Потребитель задаёт: kicker `ИНСТРУКЦИЯ · ИНСТРУМЕНТ`, заголовок в 2 строки, бейдж, путь в полосе окна (`claude.ai / новый проект`), запись экрана 16:10, субтитры, 3–4 шага с активным текущим.

- Запись экрана вставляется внутрь `.nk-window` целиком, без обрезки интерфейса; окно — главный объект кадра.
- Заголовок и шаги неподвижны на протяжении ролика; меняются только запись, субтитры и активный шаг.
- Горизонтальная версия 16:9 (1920 × 1080): левая колонка 560px — заголовок и шаги, справа окно, субтитры под окном.
