## Анимация
Каждая сцена иллюстрирует речь: документы, письма, направление передачи, ограничения, подтверждение. Не повторять одну статичную схему весь ролик. Объекты появляются последовательно с ease-out, обычно 0,25–0,45 с; допустимы лёгкое движение, масштаб, набор текста, короткое размытие графики при переходах (около 0,16 с).
Подбирать события под слова, ориентир 1–2 с между смысловыми акцентами. Не добавлять мелькание ради темпа. Логотипы Claude/Codex показывать с названиями, когда они подходят содержанию; использовать оригинальные иконки из assets, не рисовать заменители. Не вставлять эти бренды без связи с темой.
