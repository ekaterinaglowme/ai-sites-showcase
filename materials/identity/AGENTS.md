# Монтаж риллс · @nikolskaya.ai

- Проект предназначен для монтажа Reels про ИИ и автоматизацию. Рабочие материалы МТП и планы обучения ведутся в отдельных проектах.
- Подбирай нарезку, темп, субтитры, звук, вставки и обложки под конкретный ролик. Сохраняй лицо автора при правках изображения.
- Для вертикального видео используй 1080 × 1920. Визуальный ориентир — молочно-белый, чёрный и холодный голубой. Для скринкастов используй шаблон и правила в `reference/components/ScreencastFrame/`.
- В скринкасте показывай запись экрана целиком. Субтитры Manrope 30–34 px, максимум две строки, ключевое слово голубым. Остальные параметры смотри в `reference/README.md`.
- Если нужно изменить текст, сохраняй живую речь, юмор и понятные новичкам примеры. Для монтажного плана привязывай таймкоды к имеющемуся исходнику.
- Сохраняй исходники отдельно от экспортов. Для готового ролика проверь кадрирование, читаемость субтитров, синхронизацию и звук.
- Готовые ролики по согласованию пользователя загружай в подключённый Higgsfield и выдавай в чате предпросмотр и HTTPS-ссылку на MP4, доступную с iPhone. Локальный путь не выдавай за мобильную ссылку для скачивания. Исходники не загружай без отдельного запроса.

## Шаблон рилсов по умолчанию
- Для рилсов с автором применять `reference/templates/nikolskaya-reels/README.md`: это согласованный финальный стиль. Прочитать перед новым монтажом. Правила скринкастов выше сохраняются для скринкастов.
- Все финальные видео дополнительно сохранять в `/Users/ekaterina/Desktop/видео гпт/` с понятным уникальным именем, не перезаписывая другие ролики. Сохранять облачную выдачу через Higgsfield для iPhone.

## Выдача гайдов и автоответы Instagram / ChatPlace
- По просьбе пользователя настроить выдачу по кодовому слову использовать согласованный порядок: сначала отправить человеку личное сообщение со ссылкой на нужный гайд, проверить успешную отправку, затем ответить на его исходный комментарий «Отправила гайд в директ 💙» или «Отправила в директ 💙».
- Публичный ответ обязательно публиковать через «Ответить» под комментарием человека, внутри его ветки. Отдельный комментарий с @упоминанием не заменяет ответ. После публикации проверить привязку к ветке и сохранение после обновления страницы; ошибочные собственные дубли удалить.
- В автоматизации предусматривать оба действия в этом порядке. Не подтверждать отправку, если личное сообщение не отправилось. Если запрос пришёл только в директ, публичный комментарий не создавать.
- Ошибка ChatPlace не доказывает, что получатель сам остановил чат. Проверять фактический результат и не выдавать технический статус за установленное действие человека.
- При веб-отправке ответов учитывать обнаруженную ошибку Instagram: числовой ID родительского комментария может округляться в JavaScript. Проверять точное совпадение ID и итоговую ветку; длинные ID сохранять строками без потери точности.
